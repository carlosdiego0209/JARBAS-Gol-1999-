# JARBAS V2 — First Option MP5 / Gol 1999

Esta edição mantém o projeto Android original e acrescenta:
- workflow de compilação online;
- Java 17 + Gradle 8.7 para a compilação;
- painel horizontal mais legível para uso no carro;
- instruções passo a passo para gerar o APK;
- preservação do reconhecimento e síntese de voz em português do Brasil.

O projeto não altera o firmware da central First Option.
O APK é um aplicativo Android para rodar no celular.
