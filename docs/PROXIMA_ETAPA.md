# Próxima etapa do projeto

Para transformar o JARBAS em sistema automotivo completo:

1. controlador veicular (ESP32/MCU automotivo adequado);
2. medição de tensão da bateria com proteção;
3. sensor de temperatura;
4. leitura de portas;
5. GPS;
6. câmeras;
7. interface de diagnóstico;
8. histórico de manutenção;
9. aplicativo com comunicação local;
10. camada independente de segurança.

Não conectar diretamente IA a direção, freios ou acelerador.
